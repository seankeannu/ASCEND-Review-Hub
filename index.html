1. Numerical Differentiation

Forward Difference Approximation (\(O(h)\)): $$f'(x) \approx \frac{f(x+h) - f(x)}{h}$$
Backward Difference Approximation (\(O(h)\)): $$f'(x) \approx \frac{f(x) - f(x-h)}{h}$$
Centered Difference Approximation — 1st Derivative (\(O(h^2)\)): $$f'(x) \approx \frac{f(x+h) - f(x-h)}{2h}$$
Centered Difference Approximation — 2nd Derivative (\(O(h^2)\)): $$f''(x) \approx \frac{f(x+h) - 2f(x) + f(x-h)}{h^2}$$
Richardson Extrapolation for Differentiation
$$F(0) = a_0 = F(h) + \frac{F(h) - F(h/q)}{q^{-p} - 1}$$

For Centered Difference (\(p = 2\)) halving step size (\(q = 2\)):

$$a_0 = F(h) - \frac{F(h) - F(h/2)}{0.75}$$
⚡ Calculator Evaluation for Richardson Extrapolation

Store \(F(h) \to \mathbf{A}\) and \(F(h/2) \to \mathbf{B}\), then compute directly:

A + (A - B) / (2^(-2) - 1)

2. Numerical Integration

Domain Discretization: $$n = \text{number of subintervals}, \quad h = \frac{b - a}{n}, \quad x_i = a + i \cdot h$$
Midpoint Rule: $$M(f) = (b - a) f\left(\frac{a + b}{2}\right)$$
Trapezoidal Rule: $$T(f) = \frac{b - a}{2}[f(a) + f(b)]$$
Simpson's 1/3 Rule: $$S(f) = \frac{b - a}{6}[f(a) + 4f(\frac{a+b}{2}) + f(b)]$$
Composite Trapezoidal Rule: $$\int_a^b f(x)\,dx \approx \frac{h}{2} \left[ f(x_0) + 2\sum_{i=1}^{n-1} f(x_i) + f(x_n) \right]$$
Composite Simpson's 1/3 Rule (\(n\) must be even): $$\int_a^b f(x)\,dx \approx \frac{h}{3} \left[ f(x_0) + 4\sum_{i \text{ odd}} f(x_i) + 2\sum_{i \text{ even}} f(x_i) + f(x_n) \right]$$
⚡ Table Mode Shortcut for Discrete Node Generation

Press MODE → TABLE. Enter \(f(X)\), set Start: a, End: b, Step: h to generate all intermediate \(y\)-values, then evaluate composite summations.

3. Ordinary Differential Equations (IVP & BVP)

Part A: Initial Value Problems (IVP)
1. Forward Euler's Method (Explicit, 1st-Order): $$y_{k+1} = y_k + h \cdot f(t_k, y_k), \quad t_{k+1} = t_k + h$$
Y = Y + [h]*(f(X, Y)) : X = X + [h]
2. Heun's Method / Improved Euler (RK2): $$K_1 = f(t_k, y_k), \quad K_2 = f(t_k + h, \, y_k + h K_1), \quad y_{k+1} = y_k + \frac{h}{2}(K_1 + K_2)$$
A = f(X, Y) : B = f(X + [h], Y + [h]*A) : Y = Y + [h/2]*(A + B) : X = X + [h]
3. Classical 4th-Order Runge-Kutta Method (RK4): $$K_1 = f(t_k, y_k), \quad K_2 = f(t_k + \frac{h}{2}, y_k + \frac{h}{2} K_1), \quad K_3 = f(t_k + \frac{h}{2}, y_k + \frac{h}{2} K_2), \quad K_4 = f(t_k + h, y_k + h K_3)$$ $$y_{k+1} = y_k + \frac{h}{6}(K_1 + 2K_2 + 2K_3 + K_4), \quad t_{k+1} = t_k + h$$
A = f(X, Y) : B = f(X + [h/2], Y + [h/2]*A) : C = f(X + [h/2], Y + [h/2]*B) : D = f(X + [h], Y + [h]*C) : Y = Y + [h/6]*(A + 2*B + 2*C + D) : X = X + [h]
4. Implicit Backward Euler for Stiff ODEs: $$y_{k+1} = y_k + h \cdot f(t_{k+1}, y_{k+1})$$

• For \(y' = t - y \implies y_{k+1} = \frac{y_k + h(t_k + h)}{1 + h}\): X = X + [h] : Y = (Y + [h]*X) / (1 + [h])

• For \(y' = -\lambda y \implies y_{k+1} = \frac{y_k}{1 + h\lambda}\): X = X + [h] : Y = Y / (1 + [h]*[\lambda])

Part B: Boundary Value Problems (BVP)
Finite Difference Method (FDM) Substitutions: $$y''(t_k) \approx \frac{y_{k+1} - 2y_k + y_{k-1}}{h^2}, \quad y'(t_k) \approx \frac{y_{k+1} - y_{k-1}}{2h}$$
Collocation Method: $$y(t) = x_1 + x_2 t + x_3 t^2, \quad y'(t) = x_2 + 2x_3 t, \quad y''(t) = 2x_3$$

4. Partial Differential Equations (1D Heat Equation)

1D Heat Equation Discretization (FTCS Stencil): $$u_t = \alpha u_{xx}, \quad \text{Mesh ratio } r = \frac{\alpha \Delta t}{\Delta x^2}$$ $$u_i^{k+1} = u_i^k + r \left( u_{i+1}^k - 2u_i^k + u_{i-1}^k \right)$$
Stability Criterion of Explicit FTCS: $$r = \frac{\alpha \Delta t}{\Delta x^2} \le 0.5$$
⚡ Calculator Node Formula for Heat Equation

Left node = A, Center node = B, Right node = C:

Y = B + [r]*(C - 2*B + A)
